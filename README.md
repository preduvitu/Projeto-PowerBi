# Análise de Vagas de Dados

Projeto desenvolvido para coletar, tratar e analisar vagas do mercado
de tecnologia e dados.

## Tecnologias

- Python
- Pandas
- Power BI
- Power Query
- DAX

## Pipeline

Coleta de vagas
      ↓
Python
      ↓
Tratamento dos dados
      ↓
Dataset estruturado
      ↓
Power BI
      ↓
Dashboard

## Objetivo

Visualizar tecnologias, requisitos, localização e outros padrões
presentes nas vagas do mercado de dados.
